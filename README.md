## Overview

This repository contains six browser-based JavaScript exercises focused on DOM traversal, dynamic markup creation, form handling, events, and interactive page updates.

## Tech Stack

- JavaScript
- HTML
- CSS
- DOM API
- Git & GitHub

## Tasks

### Category Analysis
Reads category titles and item counts directly from the DOM.

### Dynamic Image Gallery
Generates gallery markup from an array of image objects.

### Live Name Input
Updates text content in real time while the user types.

### Login Form
Handles form submission, validates required fields, builds a data object, and resets the form.

### Background Color Switcher
Generates random colors and updates the page background on button clicks.

### Dynamic Box Generator
Creates and removes dynamically sized and colored elements based on user input.

## Learning Outcomes

- DOM selectors and traversal;
- dynamic HTML generation;
- event listeners;
- form events and validation;
- updating styles and text content;
- creating and removing DOM elements.
